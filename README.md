# MolarCoaster

## Preview the patient and admin pages

These pages use HTML and CSS and do not require npm or Node.js. Open the repository root folder in VS Code, install the **Live Server** extension if needed, then right-click the root `index.html` and choose **Open with Live Server**.

The site chooser links to both views:

- Patient website: `/customer/index.html`
- Static admin dashboard demo: `/admin-static/index.html`

Keep Live Server running while browsing. The admin view uses sample data for presentation only; it does not save appointments or patient information.
