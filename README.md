# MolarCoaster

## Preview the patient and admin pages

These pages use HTML and CSS and do not require npm or Node.js. Open the repository root folder in VS Code, install the **Live Server** extension if needed, then right-click the root `index.html` and choose **Open with Live Server**.

The site chooser links to both views:

- Patient website: `/Patient/Home%20Page/home.html`
- Static admin sign-in demo: `/admin-static/login.html`
- Static admin dashboard demo: `/admin-static/index.html`
- Admin patient directory: `/admin-static/patients.html`
- Admin clinic settings: `/admin-static/settings.html`

Keep Live Server running while browsing. The admin sign-in is a visual demo: any non-empty username and password will continue to the sample dashboard. It does not verify credentials or save appointments or patient information.
